### 👨‍💻 About Me

I am a **Full Stack Developer** and the **Founder of [Vier Labs](https://vierlabs.com/)**, focused on building modern web applications, robust backends, and production-ready digital products.

- 🏗️ **Engineering Mindset:** I care about pragmatic architecture, readable and maintainable code, and turning complex problem domains into straightforward software solutions.
- 🌐 **Full-Stack Craft:** Experienced across modern frontend frameworks (React, Next.js, TypeScript) and backend architectures (Node.js, REST APIs, document and relational databases).
- 🚀 **Founder @ Vier Labs:** Channeling software engineering rigor into bootstrapping and shipping useful web applications and tools.

> *"Simplicity precedes reliability. Build practical software that solves real problems with clean architecture and maintainable code."*

### 🚀 Featured Projects

#### 01. [ProofPilot](https://github.com/m-sohel/proofpilot) — AI Agent for Payment Dispute Defense
> **Autonomous, evidence-grounded chargeback defense engine for digital merchants.**
>
> * **Deterministic Guarantee:** Implements an evidence-first rule engine where pure code verifies all facts before any draft is generated, strictly confining LLMs to extraction and synthesis while eliminating hallucinations.
> * **Engineering Focus:** Automated dispute evidence collection, policy compliance checking, and economic dispute decisioning.
> * **Stack:** `Python` • `LLM Orchestration` • `Deterministic Verification` • `REST Architecture`  
> 🔗 [Source Code & Documentation](https://github.com/m-sohel/proofpilot)

#### 02. [Urban Spoon](https://github.com/m-sohel/UrbanSpoon) — Full-Stack MERN Restaurant Platform
> **Production-ready restaurant portal with real-time reservation inquiries and administrative management.**
>
> * **Architecture:** End-to-end full-stack web application with categorized culinary menus, customer reservation inquiry pipelines, and persistent MongoDB Atlas storage.
> * **Admin Portal:** Integrated administrative dashboard for real-time review, sorting, and status tracking of customer bookings.
> * **Stack:** `React` • `Node.js` • `Express.js` • `MongoDB Atlas` • `Tailwind CSS`  
> 🔗 [Source Code](https://github.com/m-sohel/UrbanSpoon) &nbsp;|&nbsp; 🌐 [Live Deployment](https://urbanspoon.vercel.app/)

#### 03. [JavaDSA Visual Academy](https://github.com/m-sohel/visual-javadsa) — Interactive Algorithmic Learning Engine
> **Visual-first interactive learning platform for mastering Data Structures & Algorithms in Java.**
>
> * **Interactive Visualizers:** Step-by-step, backward-steppable animated visualizations of live memory allocations, pointer shifts, and call stack operations using an ELI10 pedagogy.
> * **Modern Frontend:** Reactive state handling powered by Zustand, high-framerate motion animations, and responsive layout.
> * **Stack:** `React 18` • `TypeScript` • `Vite` • `Tailwind CSS` • `Framer Motion` • `Zustand`  
> 🔗 [Source Code](https://github.com/m-sohel/visual-javadsa) &nbsp;|&nbsp; 🌐 [Live Deployment](https://visual-javadsa.vercel.app)
